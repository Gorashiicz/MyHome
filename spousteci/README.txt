Stavba Pod Kontrolou — spouštění aplikace
============================================

SPUSTIT.bat
  Spustí vývojový server. Nechte okno otevřené.
  V prohlížeči: http://localhost:3000

SPUSTIT-a-OTEVRIT.bat
  Totéž + po pár sekundách otevře prohlížeč.

Demo přihlášení
  E-mail: demo@stavba.cz
  Heslo:  demo1234

Poznámky
  - Musí běžet PostgreSQL (služba postgresql-x64-17)
  - První instalace: v kořeni projektu spusťte npm run setup
  - Ukončení aplikace: Ctrl+C v okně serveru

Kořen projektu: složka nad touto (MyStavba)
